# foodtruck-agent

AI Voice Agent backend for **Rey Tequeño Davenport** food truck.

A bilingual (ES/EN) phone agent built with Vapi.ai that:
- Answers calls in Spanish or English (auto-detected)
- Takes customer orders and creates them in Square
- Generates a Square Payment Link and texts it to the customer (Twilio SMS)
- Answers questions about hours, location, website, contact, payment, etc.
- Transfers to a human operator when needed

## Architecture
**Stack:**
- Voice agent: Vapi.ai
- LLM: GPT-4o-mini
- TTS: ElevenLabs (Sarah)
- Transcriber: Deepgram nova-2 multi (ES/EN auto-detect)
- Backend: Node.js + Express
- Hosting: Render.com (free tier)
- Payments: Square Payment Links (NEVER captures card on call — PCI-DSS safe)
- SMS: Twilio
- Phone number: provided by Vapi (NOT Twilio)

## Endpoints

All under `POST /tools/*` and protected by `x-tool-secret` header.

| Endpoint | Purpose |
|---|---|
| `/tools/get_menu` | Returns active menu from Square |
| `/tools/create_order` | Creates order without payment link |
| `/tools/send_payment_link` | Creates order + payment link + sends SMS |
| `/tools/send_sms` | Generic SMS sender |
| `/tools/get_business_info` | Returns business info by topic and language |
| `/tools/transfer_to_human` | SMS notifies operator |

Plus `GET /healthz` (no auth) for Render health checks.

## Deployment

1. Push this repo to GitHub.
2. In Render, click New → Blueprint and point at this repo.
3. Render reads `render.yaml` and creates the service. It auto-generates `TOOL_SECRET`.
4. Manually set Square + Twilio + operator env vars in Render dashboard.
5. After deploy, copy the Render URL into `vapi-assistant.json` and import to Vapi.
6. Buy/assign a phone number in Vapi.

## Security notes

- `TOOL_SECRET` is auto-generated by Render. Vapi must send it as `x-tool-secret` header.
- `.env` is in `.gitignore`. NEVER commit real secrets.
- We never accept card data over the call. Payment is always via Square-hosted payment link.
